⚔️ Passives + Active Skills + Orchard

Generic DPS baseline: Demon God • Musclehead • Serenity • Legend
Species/element/Partner Skill builds can differ.

Getting passives

  • Breeding: main method. Aim for 2 desired passives on each parent, then combine.
  • Captured donors: save rare-passive Pals.
  • Passive implants: fix an otherwise excellent Pal instead of restarting.

Skillfruit Orchard priority

  1. Holy Burst
  2. Dragon Meteor
  3. Fire Ball
  4. Blizzard Spike / Dark Laser / Lightning Bolt / Hydro Laser / Solar Blast
  5. Beam Slicer for shorter-cooldown coverage
Skill pattern: fast/medium skill + strong mid-cooldown skill + nuke.

🏠 Your 3 Bases

Base 1 — HOME / Production

Keep: 2 Ancient Furnaces, Ancient Workbench, Ancient Power, Ancient Monitoring, Ancient Kitchen, Relic Recycler.

Targets: Orserk (Electricity), Renjishi (Kindling), Solenne (Handiwork), Silvance (Medicine). Storage beside machines.

Base 2 — MINING / Synthesizer

Ancient Material Synthesizer: no Ore/Chromite/etc. input. It consumes 800 power + one worker.

Requirement: Mining Lv.6 for minerals; Lumbering Lv.6 for wood.

Priority: Soralite → Coralum → Hexolite Quartz → Chromite → Pure Quartz, based on stock.

Workers: Aegidron for Mining; Knocklem for Mining + Transport.

Base 3 — FARM / RANCH / HATCHERY

Ancient Farm: Planting 6 + Watering 6 + Gathering 6. Each completed harvest gives 10 selected crops.

Crops: Red Berries, Wheat, Tomato, Potato, Lettuce, Carrot, Onion.

Workers: Dandilord (Planting), Shaolong (Watering), Jetragon (Gathering).

Ranch: Flame Organs • High Quality Pal Oil • High Quality Cloth • Ice Organs • Milk/Honey as needed.

Hatchery: passive breeding + condensation copies + resource breeding.

⭐ Pal Upgrade Systems

Permanent Pal order: Desired passives → good Potential → Pal Souls → ★ condensation → Awakening → Trust/finishing.

Awakening

50 matching Radiant Gems + 10 World Tree Holy Water → matching Awakening Crystal at the Ancient Workbench. Save these for permanent combat Pals.

Rule: breed/catch duplicates for easy Pals. Save expensive Starfruit for rare, difficult or unbreedable permanent Pals.

Expedition Firepower

  • Use highest-level, highest-stat spare Pals.
  • Condensation is one of the strongest Firepower upgrades.
  • Souls, Potential, Trust and Awakening improve the underlying combat stats.
  • Do not breed perfect combat passives solely for expedition duty.
World Tree expedition: passive Holy Water + Paloxite + Ancient Relics + Radiant Gems + Ancient Civilization Cores.

💰 Money / Selling

Sell surplus, not bottlenecks.
Fine: excess ranch output, unwanted loot and manufactured ammo when reserves are healthy.
Avoid: World Tree materials, Ancient/AI/Thermal Cores, Soralite, Paloxite, Holy Water, Radiant Gems and Relics.

✅ Fast Endgame Loop

  1. Run World Tree expedition.
  2. Set Synthesizer to your lowest endgame resource.
  3. Collect Ranch output; keep Flame Organs running.
  4. Keep Orchard copying a premium Skill Fruit.
  5. Run a Hard Tower for your next Legendary schematic.
  6. Kill convenient World Tree Alphas / collect Holy Water + gems.
  7. Recycle Relics.
  8. Breed one permanent combat/resource project at a time.
